## About this blog

It's an [Astro](https://astro.build/) site hosted on [GitHub pages](https://github.com/nwber/nwber.github.io). This was mostly built using agents!

However, *nothing here has been written by an LLM*. I may use one for structure, brainstorming, or for working on the technical content, but the contents of this blog are 100% organic, USDA approved human thoughts. I don't think LLM generated posts are interesting or useful.
